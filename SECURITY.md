# Security policy

## Reporting a vulnerability in anydec

Please report vulnerabilities in anydec itself, such as a crafted input that crashes the unpacker or escapes the output directory, through [GitHub private vulnerability reporting](https://github.com/stohirov/decompile-anything/security/advisories/new). Don't open a public issue for them.

## Findings in third-party firmware

If you find a vulnerability in a vendor's firmware while using anydec, report it to that vendor through their disclosure process. Don't file it here. This project doesn't host exploit code or payloads for third-party devices.
